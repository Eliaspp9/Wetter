Neuer Code für den Cloudflare-Worker

  1. Tippe auf „Code kopieren“.
  2. Bei Cloudflare: Workers & Pages, dann „wetter-proxy“, dann „Edit code“ (Code bearbeiten).
  3. Den alten Code ganz löschen und den neuen einfügen.
  4. Oben rechts auf „Deploy“ (Bereitstellen) tippen.

Danach muss auf wetter-proxy.elias-ziegler.workers.dev „"renew":true“ stehen. Deine Variablen (Passwort, Kachelmann-Schlüssel) bleiben erhalten, sie gehören nicht zum Code.
